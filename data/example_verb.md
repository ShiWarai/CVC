# Формы глаголов для создания примеров команд

При создании примеров команд важно покрывать разные грамматические формы глаголов. Это обеспечивает лучшее распознавание команд в разговорной речи.

## Таблица форм глаголов

| № | Название формы | Описание / грамматическое значение | Изменяется по | Пример (брать / взять) |
|---|----------------|-----------------------------------|---------------|------------------------|
| 1 | Инфинитив (начальная форма) | Неопределённая форма глагола, отвечает на вопросы «что делать?», «что сделать?» | — (не изменяется) | брать / взять |
| 2 | Повелительное наклонение ед. ч. (ты-форма) | Прямая команда, обращение к одному роботу/человеку | — | бери / возьми |
| 3 | Повелительное наклонение мн. ч. (вы-форма) | Команда группе или вежливое обращение | — | берите / возьмите |
| 4 | Настоящее время (только несов. вид) | Действие происходит сейчас или регулярно | лицо и число (1,2,3 л., ед./мн.) | беру, берешь, берет, берем, берете, берут |
| 5 | Простое будущее время (только сов. вид) | Действие произойдёт в будущем (однократное) | лицо и число | возьму, возьмешь, возьмет, возьмем, возьмете, возьмут |
| 6 | Составное будущее время (только несов. вид) | Будущее действие, которое будет продолжаться | лицо и число + «буду/будешь…» | буду брать, будешь брать... |
| 7 | Прошедшее время мужской род | Действие в прошлом, субъект мужского рода или робот | род, число | брал / взял |
| 8 | Прошедшее время женский род | Действие в прошлом, субъект женского рода | род, число | брала / взяла |
| 9 | Прошедшее время средний род | Действие в прошлом, субъект среднего рода или безличные конструкции | род, число | брало / взяло |
| 10 | Прошедшее время множественное число | Действие в прошлом, несколько субъектов или обобщённо | число | брали / взяли |
| 11 | Деепричастие настоящего времени | Одновременное добавочное действие (несов. вид) | — | беря |
| 12 | Деепричастие прошедшего времени | Последовательное/завершённое добавочное действие (чаще сов. вид) | — | взяв |
| 13 | Действительное причастие настоящего времени | Признак предмета по действию, которое происходит сейчас (несов. вид) | род, число, падеж | берущий, берущая, берущее, берущие |
| 14 | Действительное причастие прошедшего времени | Признак предмета по действию, которое уже произошло | род, число, падеж | взявший / бравший |
| 15 | Страдательное причастие настоящего времени | Признак предмета, который подвергается действию сейчас (несов. вид) | род, число, падеж | беремый (редко) |
| 16 | Страдательное причастие прошедшего времени | Признак предмета, который подвергся действию (чаще сов. вид) | род, число, падеж | взятый, взятая, взятое, взятые |
| 17 | Сослагательное наклонение | Желательное/условное действие («бы» + форма прошедшего времени) | род, число + «бы» | взял бы / взяла бы / взяли бы |
| 18 | Возвратные формы (с -ся/-сь) | Действие направлено на себя или взаимное | присоединяется к большинству форм | берется, возьмись, взявшись |

## Приоритетные формы для команд роботу

Для голосовых команд роботу наиболее важны следующие формы (в порядке приоритета):

### Высокий приоритет (обязательно включать)
1. **Повелительное наклонение ед.ч.** — основная форма команды: "встань", "беги", "ложись"
2. **Инфинитив** — часто используется в разговорной речи: "встать", "бежать", "лежать"
3. **Повелительное наклонение мн.ч.** — вежливая форма: "встаньте", "бегите"

### Средний приоритет (рекомендуется включать)
4. **Настоящее/будущее время 2 л. ед.ч.** — в вопросительных конструкциях: "встанешь?", "побежишь?"
5. **Сослагательное наклонение** — мягкие просьбы: "встал бы", "лег бы"
6. **Модальные конструкции** — с "надо", "нужно", "пора": "надо встать", "пора бежать"

### Низкий приоритет (опционально)
7. Прошедшее время — редко для команд, но возможно: "а ну быстро встал!"
8. Деепричастия — в составных командах
9. Причастия — почти не используются в командах

## Модальные конструкции

Помимо форм глагола, важно покрывать модальные конструкции:

| Конструкция | Пример |
|-------------|--------|
| надо + инфинитив | надо встать |
| нужно + инфинитив | нужно лечь |
| пора + инфинитив | пора бежать |
| можно + инфинитив | можно встать |
| давай + инфинитив | давай вставать |
| хватит + инфинитив | хватит лежать |
| перестань + инфинитив | перестань бегать |

## Пример применения для команды "встать" (dismiss)

| Форма | Примеры |
|-------|---------|
| Инфинитив | встать, вставать |
| Повелит. ед.ч. | встань, вставай |
| Повелит. мн.ч. | встаньте, вставайте |
| Будущее 2л. | встанешь |
| Сослагат. | встал бы |
| Модальные | надо встать, пора вставать, нужно встать |

## Пример применения для команды "равняться" (stand_at_attention)

| Форма | Примеры |
|-------|---------|
| Инфинитив | равняться, выравняться |
| Повелит. ед.ч. | равняйся, выравняйся, равняйсь |
| Повелит. мн.ч. | равняйтесь, выравняйтесь |
| Будущее 2л. | выравняешься |
| Сослагат. | выравнялся бы |
| Модальные | надо выравняться, пора равняться |
